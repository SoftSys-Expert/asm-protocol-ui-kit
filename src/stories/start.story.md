## Подключение

Порядок импортов совпадает с `packages/frontend/src/main.ts` сайта:

```ts
import "@asm-protocol/ui-kit/site/sandbox.css";
import "@asm-protocol/ui-kit/styles/tokens.css";
import "@asm-protocol/ui-kit/styles/skin-operator.css";
import "@asm-protocol/ui-kit/styles/skin-tty.css";
import "@asm-protocol/ui-kit/site/index.css";
import { setFx, getFx, resetFx } from "@asm-protocol/ui-kit/site/fx";

document.body.classList.add("skin-operator"); // либо skin-tty
setFx({ glitch: { preset: "tape-track", duration: "0.45s" } });
```

```html
<button class="button button--primary">Ответить</button>
<div class="options">
  <button class="option is-selected" aria-pressed="true">
    <span>B</span>Выполняет простые действия одно за другим
  </button>
</div>
```

`setFx` устанавливает параметры `--fx-*` и атрибуты `data-fx*` на `<html>`.
Режим `static` останавливает анимацию; `off` также отключает CRT и свечение.
Отдельные выключатели — `glitch.enabled`, `glow.enabled`, `crt.enabled`.
`resetFx()` убирает только настройки API. Без атрибута пресета остаётся `shred`.
TTY и системная настройка уменьшения движения сохраняют поведение сайта.
